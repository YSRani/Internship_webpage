# 🌐 Internship Opportunities

A modern, responsive webpage that showcases multiple internship programs with interactive cards, clean design, and easy navigation.  
Built using **HTML5** and **CSS3**, it highlights internship roles with details, hover effects, and clear call-to-action buttons.

## ✨ Features
- 📱 Fully responsive design for desktop and mobile  
- 🎨 Clean UI with gradient backgrounds and animations  
- 🧑‍🎓 Internship cards with role, duration, and location  
- 🔗 Direct action buttons for **Apply Now** and **Learn More**  

---

## 🛠️ Tech Stack
- **HTML5** – Structure & Content  
- **CSS3** – Styling (Flexbox, Grid & Hover Effects)  
- **Font Awesome** – Icons
